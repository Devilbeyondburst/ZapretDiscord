> ### Реакция антивирусов
>
> Антивирус может среагировать на WinDivert.  
> WinDivert перехватывает и фильтрует сетевой трафик и необходим для работы zapret.
> Один и тот же инструмент могут применять как безопасные, так и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы считают компоненты WinDivert потенциально опасными или относят их к хакерским инструментам. В результате файл удаляется и отправляется в карантин. Название обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте папку zapret в исключения антивируса либо отключите проверку PUA — потенциально нежелательных приложений. Например, Kaspersky предлагает настройку "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При уверенной настройке исключений предпочтительнее добавить исключение, но если вы не полностью понимаете последствия, рекомендуется отключить детектирование PUA.

## ⚙️ Использование

1. Настройте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщика по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет включить Secure DNS непосредственно в параметрах системы — [инструкция](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется
    * Владельцам роутеров Keenetic нужно активировать в настройках опцию "Транзит запросов". При отключённой опции Secure DNS на компьютере может работать некорректно

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/Devilbeyondburst/zapret-discord-youtube/releases/latest)

3. Откройте свойства архива и включите "Разблокировать". Если архив распаковывается через 7-Zip или PeaZip, этот шаг не требуется

4. Распакуйте архив в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите подходящий файл
    * Для поиска рабочей стратегии откройте **`service.bat`** → `Run Tests` → `Standard tests` → `All configs`
    * Для запуска стратегии вместе с системой выберите **`service.bat`** → `Install Service` → подходящую стратегию

## ℹ️ Что делают файлы

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавить выбранную стратегию в автозапуск Windows (services.msc)</ins>
  - **`Remove Services`** — удалить стратегию и WinDivert из служб
  - **`Check Status`** — посмотреть состояние обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** — включить или выключить обход для игр и других сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения необходимо перезапустить стратегию.**  
  Текущее состояние отображается в скобках: включено или выключено.
  - **`IPSet Filter`** — изменить режим обхода для сервисов из `ipset-all.txt`.  
  Это может помочь при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках показывается режим:
    - `none` — IP-адреса не проверяются
    - `loaded` — проверяется наличие IP в списке
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включить или выключить автоматический поиск обновлений
  - **`Replace active fakes`** — заменить используемый fake другим файлом из каталога `bin`
  - **`Update IPSet List`** — получить актуальный `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновить hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — вручную проверить наличие обновлений
  - **`Run Diagnostics`** — найти распространённые причины неисправности zapret.  
  В конце диагностики можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапной остановки работы приложения
  - **`Run Tests`** — проверить стратегии:
    - `Standard tests` — сайты из `utils/targets.txt`
    - `DPI checkers` — DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️ Частые вопросы и неисправности

### После запуска `general*` ничего не меняется

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться winws.exe (обход); его можно увидеть на панели задач.  
Если winws.exe не появился, обратитесь к [#522](https://github.com/Devilbeyondburst/zapret-discord-youtube/issues/522)

### Рабочая стратегия не найдена

- Откройте командную строку с правами администратора
- Выполните по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере

Откройте **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - Откройте файл `hosts` в созданной папке текстовым редактором, запущенным от имени администратора
  - Вставьте скопированный текст в конец `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните файл и проверьте подключение ещё раз. Если результат не изменился, убедитесь, что hosts действительно сохранён.

#### Результат не гарантируется. Если способ не помог, используйте [версию Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Devilbeyondburst/tg-ws-proxy) или одним из публичных прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Обнаружение определённого варианта может произойти не сразу: стратегия, работавшая ранее, позднее перестаёт помогать.
> В репозитории собрано много вариантов обхода. Если ни один не подходит, создайте собственную стратегию на основе одной из имеющихся и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте `service.bat` → `Run Diagnostics` и устраните найденные ошибки

- Убедитесь, что адрес ресурса присутствует в доменных или IP-списках

- Протестируйте другие стратегии, включая **`ALT`** и **`FAKE`**

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/Devilbeyondburst/zapret-discord-youtube/issues/765)

### Полная переустановка или обновление

- Сохраните добавленные вами ресурсы и другие данные
- Перезапустите устройство
- Выполните `service.bat` → `Remove Services`
- Затем откройте `service.bat` → `Run Diagnostics`; исправьте ошибки и в конце ответьте Y
- Удалите старую папку zapret
- Скачайте свежую версию со [страницы релизов](https://github.com/Devilbeyondburst/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите правой кнопкой по архиву и откройте свойства. Если внизу справа есть "Разблокировать", установите флажок, нажмите "Применить" и "ОК"
- Распакуйте архив в новую папку в корне диска; в пути не должно быть специальных символов и пробелов
- Запускайте разные скрипты `general` и проверяйте доступ к интернет-ресурсам. Если вариант не работает, закройте программу через значок замка на панели задач и попробуйте следующий
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` → `Install Service`

### Игра или приложение не работает при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может повлиять на неожиданные ресурсы.

### Античит сообщает о WinDivert

- Изучите инструкцию: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert остался среди служб

1. Узнайте имя службы в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться
- Повторно протестируйте все остальные стратегии, особенно если раньше всё работало
- См. [#251](https://github.com/Devilbeyondburst/zapret-discord-youtube/discussions/251)

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её
- Откройте `service.bat` → `Run Diagnostics` и очистите там кэш Discord
- Проверьте Discord и оцените, помогла ли очистка кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей
- Если сайт также не работает, снова проверьте все стратегии: YouTube и Discord могут открываться на разных вариантах
- См. [#252](https://github.com/Devilbeyondburst/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Devilbeyondburst/tg-ws-proxy)
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета

### Игры не работают

Игр много, поэтому проверить и исправить каждую из них невозможно.

Попробуйте универсальный порядок действий:
- через `service.bat` обновите ipset и включите `Game Filter`
- если это не помогло, дополнительно включите `ipset any`

Учитывайте: режим `ipset any` может нарушить открытие множества сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`.

Если проблема сохранится, создайте обсуждение в [Discussions](https://github.com/Devilbeyondburst/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет подходящей проблемы

- Опишите её [здесь](https://github.com/Devilbeyondburst/zapret-discord-youtube/issues)

## 🗒️ Добавление адресов других ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
